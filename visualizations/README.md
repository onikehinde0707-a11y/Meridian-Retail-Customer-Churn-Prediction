
Phase 8 – Data Visualizations

This folder contains the exported charts and interactive visualizations from the Meridian Retail customer churn analysis.

Files include:

* Customer churn by shopping channel
* Customer churn by membership tier
* Customer churn by state
* Customer churn by referral source
* Correlation heatmap
* Monthly revenue trend
* Interactive Plotly charts
* Chart captions and explanations

Note: Phase 8 visualizations use a 180-day churn threshold.
